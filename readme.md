## 代表项目

### 🎨 [AI T 恤定制平台](https://github.com/wanhei1/ai-T-shirt)
用户可完成「选款式 → 画布设计 → 预览下单」全流程，AI 图像生成由 ComfyUI 驱动。  
`Next.js 14` · `Express.js` · `PostgreSQL` · `ComfyUI` · `TypeScript`  
→ 支持中英双语界面，已部署至 Vercel，含 JWT 鉴权与订单管理。

### ⚖️ [模拟法庭多智能体系统](https://github.com/wanhei1/mock_court_multiagents)
多个 LLM Agent 分别扮演法官、原告、被告，自动完成庭审流程模拟。  
`Python` · `LLM` · `Multi-Agent`  
→ 探索 AI Agent 在结构化角色场景下的协作与对抗机制。

### 📚 [学位论文管理平台](https://github.com/wanhei1/reaseach_website)
为高校师生提供论文提交、三级审核、全文检索与数据可视化的完整解决方案。  
`Next.js` · `Supabase` · `TypeScript` · `Tailwind CSS`  
→ v2.0 相比 v1.0 页面加载性能提升 48%，新增实时数据分析面板。
